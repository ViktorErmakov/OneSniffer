# OneSniffer.YAXUNIT

Расширение с движком [YAxUnit 25.12](https://bia-technologies.github.io/yaxunit/) и серверными тестами OneSniffer (контур P0–P1).

## Состав

| Модуль | Назначение |
|--------|------------|
| `ЮТOneSnifferТесты` | Сценарии: настройки, URI/JSON/переменные, маскирование, `ПодготовитьЛог`, запись/очистка РС, входящий лог |
| `ЮТOneSnifferТестовыеДанные` | Фабрики логов и снимок/восстановление настроек |

Не покрыто (намеренно): `_ВызватьHTTPМетод` с сетью, UI/Monaco, формы.

## Запуск

1. База: конфигурация **БСП_демо** (или совместимая) + расширение **OneSniffer** + это расширение.
2. Снять с YAXUNIT безопасный режим и защиту от опасных действий.
3. EDT: запуск тестов через плагин edt-test-runner / `run_yaxunit_tests`, модуль `ЮТOneSnifferТесты`.

Предупреждения EDT `undefined-variable` на `ЛогированиеТрафика` / объекты OneSniffer — ожидаемы на этапе дизайна (другой CFE); в рантайме при обоих расширениях резолвятся.

## Обновление движка

Скопировать `exts/yaxunit` из [релиза YAxUnit](https://github.com/bia-technologies/yaxunit/releases), сохранить модули `ЮТOneSniffer*`, сравнить/объединить в EDT.
