## Перед модерацией

1. Загрузить все PNG в «Изображения», вставить в текст из этого блока (не с внешних сайтов).  
2. Приложить `OneSniffer_0.0.0.3.cfe` в «Файлы».  
3. Проверить, что в конце есть секция **«Обновления»** (новые версии — сверху).  
4. Один раз явно: логируются только вызовы, переведённые на API (opt-in).  

## Замечание по скринам UI

`list-form.png`, `settings-form.png`, `editor.png` — иллюстративные мокапы интерфейса (EDT WYSIWYG без `-DnativeFormBufferedLayoutRender` и занятая ИБ не дали снять живые кадры). Перед релизом желательно заменить на скрины с рабочей базы «БСП демо 3.1.11» — те же имена файлов.
