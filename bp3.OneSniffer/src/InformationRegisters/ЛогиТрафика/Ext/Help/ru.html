OneSniffer: логирование исходящего HTTP-трафика в 1С:Предприятие 8

OneSniffer — расширение конфигурации 1С (тип AddOn, префикс OneSniffer_), аналог HTTP-сниффера внутри платформы. Подходит для сред без стороннего ПО на рабочей станции, CI/сборочных линий и отладки интеграций.

Важно: логируются только вызовы, которые приложение явно перевело на API расширения. Автоматического перехвата всех HTTP-вызовов платформы нет (opt-in).

Реализованы исходящий и входящий HTTP: исходящие вызовы — через _HTTPСоединение._ВызватьHTTPМетод, входящие HTTP-сервисы — через публичный API _HTTPСервис (см. ниже).

Требования

  • Платформа 1С:Предприятие 8.3.17 и выше
  • Расширение подключается к конфигурации-хосту как AddOn
  • Константа OneSniffer_ДатаЧтенияЖР и автоматическая регламентная очистка по расписанию требуют режима совместимости расширения не ниже 8.3.16 (константы в расширениях доступны с этой версии). Режим совместимости расширения не может быть выше, чем у конфигурации-хоста — см. режим совместимости ниже 8.3.16
  • Для записи в журнал регистрации и фоновых заданий желательна БСП (ОбщегоНазначения, ДлительныеОперации, Пользователи)

Быстрый старт

  1. Подключите расширение OneSniffer к информационной базе.
  2. Откройте Логи трафика (OneSniffer) — команда в интерфейсе или через регистр сведений ЛогиТрафика.
  3. Нажмите Настройки логирования, включите Включено логирование и выберите места хранения (РС и/или ЖР). Сохраните настройки.
  4. На форме списка нажмите Редактировать, затем в меню Инструменты выберите тестовый запрос и нажмите Выполнить.
  5. Убедитесь, что запись появилась в списке (или импортировалась из ЖР, если выбран только журнал регистрации).

Возможности

  • перехват и запись исходящих вызовов HTTP через обёртку _HTTPСоединение._ВызватьHTTPМетод;
  • запись входящих вызовов HTTP-сервисов через _HTTPСервис.ЗаписатьВходящийЛог;
  • демо HTTP-сервис расширения OneSniffer_Демо (GET …/hs/onesniffer/ping) и кнопка «Демо входящий HTTP (IIS)» на форме списка логов;
  • просмотр и редактирование тел в Monaco Editor (подсветка JSON / REST);
  • превью картинок из ответа (image/* и base64 в JSON) на вкладке «Картинки»;
  • повтор и редактирование запроса прямо в редакторе (режим Редактировать, markdown-подобный формат .rest), с возможностью раскрыть редактор на весь экран кнопкой Развернуть;
  • экспорт в markdown, curl, код 1С; импорт логов из файла;
  • маскирование заголовков Authorization, Cookie, X-API-Key при записи;
  • догрузка записей из журнала регистрации (успешные вызовы и ошибки).

Поддерживаемые форматы тел:

  • JSON в двоичных данных;
  • Gzip + JSON (распаковка при записи ответа).

Внедрение в конфигурацию-хост

Режим совместимости хоста ниже 8.3.16

Собственные константы в расширении доступны только при режиме совместимости 8.3.16 и выше. Если у конфигурации-хоста режим совместимости ниже (типично для ряда типовых на БСП), расширение с константой OneSniffer_ДатаЧтенияЖР не подключится или не сохранится.

В этом случае при встраивании:

  1. Удалите из расширения константу OneSniffer_ДатаЧтенияЖР (и ссылки на неё в составе подсистемы / конфигурации, если конфигуратор или EDT их покажут).
  2. Подключите расширение к базе.
  3. На форме Настройки логирования вручную укажите Срок хранения (дни) и при необходимости нажмите Выполнить сейчас, чтобы сразу очистить устаревшие записи. Автонастройка регламентного задания по расписанию в этом режиме недоступна — очистку запускайте вручную через «Выполнить сейчас» или настройте РЗ средствами БСП/конфигуратора.

Импорт исключений из ЖР с меткой «дата чтения» без константы тоже ограничен: поле Дата чтения ЖР на форме опирается на удалённую константу.

Поиск мест замены

Найдите в коде хоста вызовы:

HTTPСоединение.ВызватьHTTPМетод(...)

Также могут использоваться Получить, ОтправитьДляОбработки, Записать, Изменить, Удалить — они не перехватываются расширением. Сведите вызовы к ВызватьHTTPМетод или используйте обёртку только для этого метода.

Поиск в EDT: Поиск → Найти в проекте по строке ВызватьHTTPМетод.

Замена вызова

Было:

Ответ = HTTPСоединение.ВызватьHTTPМетод(HTTPМетод, HTTPЗапрос, ИмяВыходногоФайла);

Стало:

Ответ = _HTTPСоединение._ВызватьHTTPМетод(
    HTTPСоединение, HTTPМетод, HTTPЗапрос, ИмяВыходногоФайла, ИмяСобытия);

| Параметр | Описание | |----------|----------| | HTTPСоединение | Тот же объект соединения, что использовался ранее (первый параметр обёртки) | | HTTPМетод, HTTPЗапрос, ИмяВыходногоФайла | Как в платформенном вызове | | ИмяСобытия | Необязательный. Произвольное имя для группировки в списке логов |

При выключенном логировании обёртка выполняет прямой вызов платформы без лишней обработки.

Длительность исходящего запроса (колонка «Длительность, с» в списке логов) считается автоматически — от создания лога до записи ответа (round-trip + обработка на стороне API).

Имена событий

Если ИмяСобытия пустое, используется эвристика по URL (например, сервисы интернет-поддержки 1С) или «Произвольный запрос».

Для кастомизации имён в хосте заполните модуль ЛогированиеТрафикаПереопределяемый.ИмяСобытия:

Импорт и экспорт файлов

  • Сохранить логи в файл — markdown по протоколу OneSniffer (заголовок события, метод, URL, заголовки, тела, ответ).
  • Загрузить логи из файла — импорт ранее сохранённых или внешних логов в том же формате.

Автоматическая запись каждого лога в файл по переменной окружения — запланирована (фаза 2).

FAQ

Почему в списке пусто после внедрения?

Расширение не перехватывает вызовы автоматически. Проверьте: (1) включено логирование в настройках; (2) в коде хоста вызов заменён на _HTTPСоединение._ВызватьHTTPМетод; (3) при записи только в ЖР включён импорт из ЖР или выполните повторный запрос с формы.

Хост с режимом совместимости ниже 8.3.16

Константы в расширении недоступны. Удалите OneSniffer_ДатаЧтенияЖР при встраивании (см. раздел внедрения). Срок хранения на форме настроек задайте вручную и при необходимости нажмите Выполнить сейчас.

Безопасность: попадут ли пароли в лог?

Заголовки Authorization, Cookie, X-API-Key маскируются при записи в РС и ЖР. На форме авторизации доступен просмотр Bearer по кнопке «Показать содержимое». Не включайте запись тел на продуктиве без необходимости.

Только журнал регистрации, без РС

Возможен режим «только ЖР». После произвольного или повторного запроса с формы выполняется синхронный импорт из ЖР, если включён соответствующий параметр.

Производительность

Запись больших тел в РС и ЖР на высокой нагрузке дорога. Отключайте «писать тело», либо задайте Максимальный размер тела, КБ (текст усекается, бинарь — заглушка).

Входящий HTTP

В обработчиках HTTP-сервисов конфигурации-хоста (или в HTTP-сервисе расширения) вызывайте API расширения один раз в конце обработки:

ИмяСобытия = "МойСервис.Обработчик";
// Необязательно: замер времени обработки на сервере
ВремяНачалаЗамера = ТекущаяУниверсальнаяДатаВМиллисекундах();
Попытка
    // … формирование HTTPСервисОтвет …
    _HTTPСервис.ЗаписатьВходящийЛог(Запрос, ИмяСобытия, Ответ, , ВремяНачалаЗамера);
    Возврат Ответ;
Исключение
    _HTTPСервис.ЗаписатьВходящийЛог(Запрос, ИмяСобытия, , ИнформацияОбОшибке(), ВремяНачалаЗамера);
    ВызватьИсключение;
КонецПопытки;

Длительность для входящих — опциональна. Пятый параметр ВремяНачалаЗамера — отметка начала в миллисекундах универсального времени (ТекущаяУниверсальнаяДатаВМиллисекундах()), которую нужно объявить в начале обработчика и передать в вызов записи лога. Если параметр не передан — в лог пишется 0. Для исходящих через _ВызватьHTTPМетод длительность считается автоматически.

Минимальный вариант без замера:

_HTTPСервис.ЗаписатьВходящийЛог(Запрос, ИмяСобытия, Ответ);

Демо без правок хоста: опубликуйте базу в IIS, заполните в БСП константу АдресПубликацииИнформационнойБазыВЛокальнойСети (или «в Интернете»), включите логирование. На форме списка: «Демо входящий HTTP (IIS)» → в редакторе появится GET к …/hs/onesniffer/ping → «Выполнить». Ожидаются две записи: исходящая (OneSniffer.ДемоИсходящий) и входящая (OneSniffer.ДемоВходящий, Входящий = Да).

Проверка снаружи (curl), если известен базовый URL публикации {BASE}:

curl -s "{BASE}/hs/onesniffer/ping"

Ответ: {"service":"OneSniffer","ping":"ok"}.

Ограничения

  1. Opt-in — без замены вызовов в хосте логов не будет.
  2. Обёрнут только HTTPСоединение.ВызватьHTTPМетод.
  3. Расширение AddOn не может подписаться на чужие модули без правок хоста.
  4. В логах могут оказаться чувствительные данные — настройте маскирование и политику хранения.
